# 📝 Exercícios

Durante esta fase serão desenvolvidos os seguintes exercícios:

### 01 — Página Pessoal

Criação de uma página apresentando informações pessoais e profissionais.

### 02 — Página de Currículo

Criação de uma página de currículo utilizando HTML5.

### 03 — Página de Produto

Criação de uma página para apresentação de um produto.

### 04 — Formulário de Cadastro

Criação de um formulário utilizando diferentes tipos de campos e controles HTML.

### 05 — Página de Restaurante

Criação de uma página para apresentar um restaurante, seu cardápio e informações de contato.
